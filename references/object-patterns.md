# 真实物件动作模式

## 标准关系

1. 拉入：纸签、夹子或线绳从不同方向拉人进入任务。
2. 涌出：票据机、抽屉或信封吐出任务，Silas 挡、接或推回。
3. 回流卡点：卷尺、挂绳或回弹带形成回路和卡扣，Silas 解开。
4. 审查：透明文件袋、夹板、红笔或卡尺定义检查区，Silas 量、圈或改。
5. 重贴：标签机、布章或行李牌重命名身份，Silas 拉住或重贴。
6. 筛选：茶漏、漏斗或滤纸过滤卡片，Silas 推入、接住或救回。
7. 加压：纸镇、弹簧夹或文件托盘持续加码，Silas 扛住或托起。

## 混合媒介约束

- 物件要像真实摄影实物，不是手绘图标。
- Silas 必须以二维墨线和彩铅存在，手部接触物件并产生可信受力。
- 同一画面只保留一个物理冲突；若沿用母版物件，必须改变空间关系和动作。
- 禁止截图、界面、品牌标志、装饰性科技符号和主题名词清单。

## 长卷物件

每个阶段选择一个可触碰的记忆物：空白笔记本、钥匙、纸模型、反馈印章、线轴、打开的盒子等。摄影实物承载阶段，手绘 Silas 承担动作。
