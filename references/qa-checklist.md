# 生成后 QA

## 必须通过

- [ ] 画面尺寸和模式匹配：标准 16:9，长卷约 2.6:1 到 3:1。
- [ ] Silas 的短黑发、窄椭圆黑墨镜、暖灰褐立领套装和黑鞋一致。
- [ ] Silas 是扁平墨线和彩铅，不是 2.5D、黏土、塑料公仔或真人。
- [ ] 真实物件保持摄影材质，没有整体变成插画。
- [ ] 手与主物件真实接触；身体重心、动作线和物件受力一致。
- [ ] 角色脚下有轻接触阴影，不像悬浮贴纸。
- [ ] 画面大留白，主物件不过大，配件不超过 2 个。
- [ ] 中文标签只有 2-4 个且完全正确，没有多余文字。
- [ ] 不看说明也能在 3 秒内说出冲突。
- [ ] 至少 3 个构图要素不同于所选母版。

## 长卷追加检查

- [ ] 5-8 个节点从左到右形成连续叙事。
- [ ] 路线自然起伏，节点不等距，不是流程图或规律波形。
- [ ] 每个节点都是摄影实物，并出现同一身份的手绘 Silas 动作。
- [ ] 没有虚构具体履历、日期、数字或品牌。

第一张结果一律标为候选。查看原图后逐项检查；任一必须项失败，就修正提示词或重新生成，不作为交付图。
