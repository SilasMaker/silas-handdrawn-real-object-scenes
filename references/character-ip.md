# Silas 扁平手绘角色 IP

## 身份锚点

使用 `assets/identity/silas-handdrawn-identity.png` 作为 identity reference，只继承身份与绘画语言，不继承角色表的网格、多姿势排版或文字。

固定识别点：

- 年轻东亚男性的极简手绘化身，短黑发形成清楚的深色轮廓。
- narrow oval black sunglasses 始终保留，不能改成圆眼镜、透明眼镜或普通黑点眼睛。
- 暖灰褐立领套装以不均匀彩铅轻铺色，黑色简洁鞋。
- compact 2.3-head proportions，头身短小但不幼态；手脚为细而有力的手势线。
- thin expressive black ink 轮廓略有手绘抖动，不能变成矢量图标或粗黑漫画线。

## 动作规则

- Silas 必须拉、推、接、挡、解、标、扶或筛，手必须接触主物件。
- 动作方向、身体倾斜和物件受力一致，不能只画动作线冒充接触。
- 标准模式中角色高度通常占短边的 10% to 14%；可为动作清晰度轻微放大，但仍保持小人感。
- 表情克制、认真、略带打工人的轻紧张，不做可爱卖萌、英雄姿势或夸张哭笑。

## 禁止项

- 不生成 2.5D、黏土、毛毡公仔或真实人像。
- 不让角色失去发型、墨镜、立领套装而变成匿名黑色小人。
- 不做大头萌系、儿童绘本动物比例、贴纸人物或表情包。
